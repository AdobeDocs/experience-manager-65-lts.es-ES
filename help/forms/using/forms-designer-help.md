# Ayuda de Forms Designer {#form-designer-help}

AEM Forms Designer es una aplicación de escritorio para crear y administrar formularios adaptables basados en PDF y XFA en Adobe Experience Manager Forms. Utilice los recursos siguientes para empezar, explorar ejemplos y hacer referencia a las funciones de scripts de Designer para esta versión 6.5 LTS.

* [Uso de Designer](https://www.adobe.com/go/learn_aemforms_designer_65_lts): información general sobre el espacio de trabajo de Designer y los conceptos básicos de creación.
* [Tutoriales de inicio rápido de Designer](https://www.adobe.com/go/learn_aemforms_designer_quick_start_65_lts): tutoriales paso a paso para empezar a usar Designer.
* [Ejemplos de Designer](https://www.adobe.com/go/learn_aemforms_designer_samples_65_lts): formularios de ejemplo descargables que puede abrir y adaptar en Designer.
* [Conceptos básicos de scripts de Designer](https://www.adobe.com/go/learn_aemforms_scriptingBasics_65_lts): una introducción a los scripts en formularios Designer.
* [Referencia de scripts de Designer](https://www.adobe.com/go/learn_aemforms_scriptingReference_65_lts): la referencia completa para objetos y métodos de scripts en Designer.
* [Referencia de FormCalc de Designer](https://www.adobe.com/go/learn_aemforms_formCalc_65_lts): la referencia completa de FormCalc, el lenguaje de cálculo integrado de Designer.
